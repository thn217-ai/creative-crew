You are building a NEW project for the Google Cloud Agentic Cinema Hackathon.

PROJECT GOAL

Build a functional web application where a filmmaker gives one creative brief and an AI creative crew turns it into a coherent pre-production package.

Working product concept:

ONE BRIEF
→ AI CREATIVE CREW
→ ONE PRODUCTION-READY PRE-PRODUCTION PACKAGE

The user should feel like they are working with a capable creative organization, not manually operating a collection of AI chatbots.

PRODUCT

Working name:

CREATIVE CREW

Temporary name is acceptable. Architecture matters more than branding at this stage.

Target user:

Filmmakers, directors, producers, screenwriters, creative agencies, and production teams.

Core problem:

Turning a loose creative idea into something production-ready requires multiple kinds of expertise:

* concept development
* writing
* visual direction
* scene planning
* production planning
* consistency checking

General-purpose AI can generate individual pieces.

This product coordinates those pieces into one coherent workflow.

CORE USER JOURNEY

User enters a creative brief.

Example:

“Create a 60-second launch film for a contemporary Saudi coffee brand in Riyadh. The film should feel youthful, intimate and cinematic without relying on stereotypical Saudi imagery.”

The system:

1. Understands the brief.
2. Creates structured project state.
3. Determines the necessary creative work.
4. Coordinates specialized agents.
5. Produces a creative treatment.
6. Produces a script.
7. Produces visual direction.
8. Produces a scene breakdown.
9. Produces a shot list.
10. Produces production requirements.
11. Runs creative QA.
12. Presents everything as one coherent pre-production package.

AGENT MODEL

Start with ONLY these agents:

1. Orchestrator

Responsibilities:

* understand user intent
* create structured project state
* determine workflow
* route tasks
* maintain dependencies
* determine when work is complete

The user should NOT manually select agents.

2. Creative Director Agent

Produces:

* central creative idea
* tone
* emotional direction
* creative treatment
* campaign/film coherence
* visual and narrative principles

3. Writer Agent

Produces:

* script
* voiceover where relevant
* dialogue where relevant
* scene-level narrative
* messaging

4. Art Director Agent

Produces:

* visual language
* palette direction
* environment
* style references
* composition principles
* wardrobe/production-design direction where relevant

5. Production Planner Agent

Produces:

* scene requirements
* location requirements
* talent requirements
* props
* production dependencies
* shot list
* practical execution notes

6. Creative QA Agent

Evaluates outputs against the original brief.

Checks:

* alignment with intent
* contradictions
* visual consistency
* story consistency
* production feasibility
* unwanted clichés
* missing requirements
* continuity problems

QA should return structured findings.

Do not let the QA agent generate endless alternatives.

Its job is to determine whether work passes or requires correction.

IMPORTANT ARCHITECTURAL PRINCIPLE

Use:

structured state

+
QA

The feed is a project decision/activity surface, not AI theatre.

USER INTERVENTION

Allow the user to make a meaningful creative change.

Example:

“Keep the concept, but make it younger and less luxurious.”

The system should determine which downstream outputs are affected.

At minimum demonstrate basic dependency awareness:

User changes creative direction
→ affected script or visual direction becomes outdated
→ relevant agents rerun
→ QA reruns
→ package updates

Do not rebuild unaffected work unnecessarily when avoidable.

* keep visual consistency as much as feasible

Storyboard generation is secondary to the core agent workflow.

Do not block the whole project if image generation becomes technically risky.
